# Brand logo

`first-line-holidays.svg` is a **temporary placeholder**.

Replace it with the official First Line Holidays logo file supplied by the brand:

1. Drop the official file into this folder.
2. Name it `first-line-holidays.svg` (or `.png`) so no code changes are needed,
   OR update the `src` in `components/Logo.jsx`.
3. Keep a transparent background. Recommended width: 600px+ for PNG.

Do not redesign, recolour, crop or distort the official logo.
